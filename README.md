### ALGO-000023: P versus PSPACE
- **Subfield:** Structural complexity
- **Open:** Prove or refute that every polynomial-space computation can be performed in polynomial time.
- **Status:** Open since the 1970s. Time- and space-hierarchy theorems separate other resource levels but do not separate P from PSPACE.
- **Type:** theory
- **Why:** Determines whether polynomially bounded memory can support fundamentally more computation than polynomially bounded time.
- **Key works:** Stockmeyer and Meyer (1973), *Word Problems Requiring Exponential Time*; Arora and Barak (2009), *Computational Complexity*.
- **Related:** Formal verification—tractability of temporal-logic model checking; game theory—efficient solution of succinct games.
